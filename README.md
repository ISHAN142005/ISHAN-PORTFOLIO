## Tech Stack & Architecture

- **Frontend Framework:** React 18 + Vite + TypeScript
- **Styling & Design System:** Tailwind CSS (`#020617` / `#0f172a` dark-slate developer theme with `#38bdf8` / `#3b82f6` accents)
- **Motion & Icons:** Framer Motion + Lucide React
- **CI/CD & Hosting:** GitHub Actions (`actions/deploy-pages@v4`) deploying automatically to GitHub Pages on every push to `main`
